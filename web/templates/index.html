How to create a PAT?
ℹ️
To generate a Personal Access Token:
1. Log in to your Jira instance
2. Click your avatar (top-right) → Profile
3. In the left panel, click Personal Access Tokens
4. Click Create token, give it a name, set expiry
5. Copy the token and paste it above

Note: PAT is available in Jira Server 8.14+ and Data Center 8.14+
